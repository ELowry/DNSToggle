<p>O DNS Toggle é um pequeno app para Android que permite alternar e automatizar facilmente o DNS Privado do seu celular pelas Configurações Rápidas.</p><blockquote><p><b>IMPORTANTE:</b><br /><i>Para modificar as configurações do sistema relacionadas ao DNS Privado, este app requer a permissão <tt>WRITE_SECURE_SETTINGS</tt>. Você precisa ter um dispositivo com root, usar o Shizuku ou conceder a permissão manualmente via ADB:</i><br/>&emsp;<tt>adb shell pm grant com.ericlowry.dnstoggle android.permission.WRITE_SECURE_SETTINGS</tt></p></blockquote><p><big><b>Recursos</b></big></p><ul><li><b>Bloco das Configurações Rápidas</b>: alterne o DNS Privado diretamente pelo painel de Configurações Rápidas.</li><li><b>Provedores de DNS personalizados</b>: defina um ou mais nomes de host preferidos (por exemplo, dns.nextdns.io) e alterne facilmente entre eles.</li><li><b>Filtro de Wi-Fi</b>: desativa automaticamente o DNS Privado quando você se conecta a redes Wi-Fi específicas.</li><li><b>Bloqueio automático</b>: adiciona automaticamente à lista de bloqueio a rede Wi-Fi atual quando o DNS Privado causa problemas de conectividade.</li><li><b>Substituição para VPN</b>: aplica automaticamente um nome de host de DNS específico ou desativa completamente o DNS Privado sempre que uma VPN estiver ativa no dispositivo.</li><li><b>Backup e restauração</b>: exporte e importe sua configuração usando arquivos protegidos por senha.</li><li><b>Nome do bloco dinâmico</b>: altere o nome do bloco das Configurações Rápidas.</li><li><b>Ocultar ícone do app</b>: mantenha a tela inicial limpa sem perder o acesso pelo bloco das Configurações Rápidas.</li></ul><p><big><b>Privacidade e permissões</b></big></p><ul><li>Sem rastreamento, anúncios ou coleta de dados.</li><li>As permissões de localização são opcionais e usadas apenas para identificar os nomes das redes Wi-Fi no recurso de filtro de SSID. Elas nunca são usadas para rastrear sua localização física.</li></ul>
