<p>DNS Toggle es una pequeña aplicación de Android que te permite activar y automatizar fácilmente el DNS privado de tu teléfono a través del panel de Ajustes rápidos.</p><blockquote><p><b>IMPORTANTE:</b><br /><i>Para modificar la configuración del sistema DNS privado, esta aplicación requiere el permiso <tt>WRITE_SECURE_SETTINGS</tt>. Debes tener un dispositivo rooteado, usar Shizuku o concederlo manualmente mediante ADB:</i><br/>&emsp;<tt>adb shell pm grant com.ericlowry.dnstoggle android.permission.WRITE_SECURE_SETTINGS</tt></p></blockquote><p><big><b>Características</b></big></p><ul><li><b>Mosaico de Ajustes Rápidos</b>: Activa/desactiva el DNS privado directamente desde el panel de Ajustes Rápidos.</li><li><b>Proveedores DNS Personalizados</b>: Define uno o más nombres de host preferidos (por ejemplo, dns.nextdns.io) y cambia entre ellos sin problemas.</li><li><b>Filtrado Wi-Fi</b>: Desactiva automáticamente el DNS privado cuando te conectas a redes Wi-Fi específicas.</li><li><b>Bloqueo Automático</b>: Añade automáticamente a la lista negra el SSID Wi-Fi actual cuando el DNS privado causa problemas de conectividad. problemas.</li><li><b>Anulación de VPN</b>: Aplique automáticamente un nombre de host DNS específico o desactive completamente el DNS privado cuando una VPN esté activa en su dispositivo.</li><li><b>Copia de seguridad y restauración</b>: Exporte e importe su configuración mediante archivos cifrados con contraseña.</li><li><b>Etiquetado dinámico de mosaicos</b>: Cambie el nombre del mosaico de Configuración rápida.</li><li><b>Ocultar icono de la aplicación</b>: Mantenga su pantalla de inicio limpia mientras mantiene el acceso a través del mosaico de Configuración rápida.</li></ul><p><big><b>Privacidad y permisos</b></big></p><ul><li>Sin seguimiento, sin anuncios y sin recopilación de datos.</li><li>Los permisos de ubicación son opcionales y solo se utilizan para identificar los nombres de las redes Wi-Fi para la función de filtro SSID. Nunca se utilizan para rastrear su ubicación física.</li></ul>
