DNS Toggle est une petite application Android qui vous permet d'activer et de désactiver facilement le DNS privé de votre téléphone via le panneau des paramètres rapides.

**IMPORTANT:**

Pour modifier les paramètres système du DNS privé, cette application nécessite l'autorisation _WRITE_SECURE_SETTINGS_. Vous devez soit avoir un appareil rooté, soit l'accorder manuellement via la commande ADB suivante:

_adb shell pm grant com.ericlowry.dnstoggle android.permission.WRITE_SECURE_SETTINGS_

**Fonctionnalités**

- **Tuile de paramètres rapides**: Activez/désactivez le DNS privé directement depuis le panneau de configuration rapide.
- **Fournisseur DNS personnalisé**: Définissez votre nom d'hôte préféré (ex: dns.nextdns.io).
- **Filtrage par SSID**: Désactivez automatiquement le DNS privé lors de la connexion à des réseaux Wi-Fi spécifiques.
- **Détection de VPN**: DNS Toggle détecte automatiquement l'utilisation d'un VPN et applique la configuration DNS privé de votre choix.
- **Étiquetage dynamique de la tuile**: Renommez l'étiquette des paramètres rapides.
- **Masquer l'icône de l'application**: Gardez votre écran d'accueil propre tout en conservant l'accès via la tuile de paramètres rapides.

**Confidentialité et autorisations**

- Pas de suivi, pas de publicité et pas de collecte de données.
- Les autorisations de localisation sont uniquement utilisées pour identifier les noms des réseaux Wi-Fi pour la fonctionnalité de filtrage par SSID. Elles ne sont jamais utilisées pour suivre votre position physique.
